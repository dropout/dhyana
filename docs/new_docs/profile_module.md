# Profile Module

## Overview
Profile module is responsible for managing user profile information, including personal details, profile picture, and profile settings.

## Features

- User can complete their profile after signing up with the profile wizard.
- User can view and edit their profile information.
- User can view and edit their profile settings.
- User can update their profile statistics with session data.
- User can delete their account.

## Notable behaviours
- Consecutive days in the profile statistics are always validated and updated when loading profile
